## 加工

- 保留原坐标，不手绘、不补画、不简化省界；筛选原始 CHN/HKG/MAC/TWN 分组。
- 原数据含 32 个 CHN 要素、18 个 HKG 要素、1 个 MAC 要素、21 个 TWN 要素。HKG/MAC/TWN 分组各自进行几何合并；原始单列的西沙要素与海南分组合并，得到 34 个浏览目录。没有绘制连接线或把不相邻岛屿连成面。
- 上述分组是浏览目录加工，**不能证明岛礁行政归属符合权威标准**；两岸岛屿的省级归属、边界争议地区、南海诸岛完整性均需专项复核。
- 相邻关系仅从源几何共用的线段计算，不把点接触、隔海相望当作接壤；结果不是权威相邻关系名录。
- 地形原图裁切 65–145°E、0–60°N，按 Web Mercator 重投影。经度保留原采样，纬度采用双线性重采样；JPEG 输出。若直接将经纬度原图贴到 Leaflet，会造成纬向错位，本版本已避免。
- 地形色彩是高程与气候的组合，不能用统一色阶反推精确海拔，也不能据此绘制三级阶梯分界。未新增三级阶梯、高原、盆地、平原、山脉、水系的数据。

## 尚未通过的关键核验

1. 自然资源部标准地图服务 `https://bzdt.ch.mnr.gov.cn/` 和民政部 `https://www.mca.gov.cn/` 在当前环境返回代理 403，未完成现行权威资料对照。
2. Natural Earth 明确是小比例尺综合制图资料，其 Admin 1 说明标注 beta，并承认更新、编码等局限。不能以“公开许可”代替“现势性和行政表达正确”的核验。
3. 国界表达、行政边界现势性、岛礁与属岛完整性、港澳填海边界和岛屿归并未认证；不得通过手工补线使其看起来符合标准。
4. 在这些问题解决前，不应将本预览作为满足“完整中国及34省级权威轮廓”的正式版本合并发布。

## 后续替换要求

应取得许可适当、坐标系明确、有日期和比例尺的权威政区数据，与具有明确版本/审图号的标准地图核对。标准地图公开可看，不自动赋予下载矢量、描摹或再分发许可。

数据替换只需遵循现有 FeatureCollection 契约（唯一 id、名称、几何、标签位置和已验证相邻关系），不必改写地图或记忆挑战。新图层通过 `nationalAtlas.registerLayer(id, leafletLayer)` 注册，并添加对应 `data-map-layer` 开关。

## 重建

`scripts/prepare_national_data.py` 使用固定上游 Git SHA，断言几何有效、目录齐全，记录输出哈希。需预先获取脚本内列出的两个上游仓库到 `/tmp/shanhe-natural-earth-*`，并安装 Pillow、numpy、shapely。应用运行和浏览器测试不依赖这些制图工具。
