山河志 V0.3 · 离线资料预览

1. 将 ZIP 下载到 Windows 电脑，右键 → 全部提取。
2. 双击 shanhe-v0.3-preview.html，用 Edge 或 Chrome 打开。
3. 不用安装 Python，不用运行命令，不用启动服务器；全国总图无需联网。
4. 可操作省界和名称开关、点击高亮、选择省区、聚焦、拖动与缩放。
5. 看手机布局：按 F12，再按 Ctrl+Shift+M，选择手机尺寸或输入宽度 390；再次按快捷键退出。部分电脑需按 Fn+F12。

地形与 GeoJSON 原文件字节未修改，只内嵌到 HTML。此包仅供体验，现代政区和领土/岛礁表达尚未完成权威核验，不作为正式行政地图发布。
陕西和记忆挑战入口保留；原有在线底图仍需联网。file:// 下的本地存储与线上网站相互独立，不会迁移或删除线上已有数据。
当前环境禁止 file:// 导航；已通过 Linux Chromium 独立 HTML 内存载入的桌面/手机模拟检查。未直接验证 Windows 双击打开、Windows Edge、Safari 或实体手机。
